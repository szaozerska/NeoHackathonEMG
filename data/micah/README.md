# data/micah

This directory is intentionally tracked in Git at Micah's request.

- `dynamic/`: published dynamic sessions, with lossless compressed originals,
  original participant labels and a separate exploratory review. Suspected label
  mistakes never silently overwrite those labels.
- `static/`: live static Shield/Sword hold recordings and their labels. Open
  http://127.0.0.1:8785/static on the collection Mac, or `/static` on another
  running partner bench.

Keep static and dynamic conditions separate. A shared wearing-session ID means
they are not independent wearing-session evaluations. Data here are development
examples unless explicitly reserved otherwise. Sensor patterns alone cannot
prove mental intent, physical force or the correctness of a selected gesture.

The session manifest documents source hashes and modality availability. No
camera, Meta credentials or Kinesis feed tokens are published with these data.
