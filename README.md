# NeoHackathon EMG

Hackathon workspace for pitch materials, individual contributions, Unity work, and approved team builds.

```text
Pitch/
Product/
  Micah/
    Unity/
    Codex/
      Unity/
  Q/
  Ken/
  Sofi/
  AI agents/
    Codex/
      Unity/
  current/
  Unity/
  GitHub's Accumulated/
```

- `Pitch`: presentation materials, demo scripts, and pitch research.
- Individual folders: each contributor's experiments, code, and notes.
- `AI agents`: agent contributions, organized by agent. Codex has a Unity tools placeholder.
- `current`: approved, finalized team builds only. Keep empty until Micah explicitly authorizes promotion.
- `Product/Unity`: reserved for shared Unity work after team approval.
- `GitHub's Accumulated`: external source repositories used to build the product; keep upstream licenses and provenance.

For now, all new Codex implementation work belongs in `Product/Micah/Codex/Unity`, and Micah's Unity work belongs in `Product/Micah/Unity`. Shared Unity and AI agent locations are placeholders until authorized.

Unity setup and commands: [local guide](Product/Micah/Codex/Unity/README.md).

The scaffold was integrated with the upstream repository using `Product/Micah/Codex/Unity/push-scaffold.sh`.
